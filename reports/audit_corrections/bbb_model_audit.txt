==============================================================
SECTION 4: IDENTIFIED GAPS
==============================================================

GAP 1: No test prediction file saved
  The BBB model directory contains only bbb_model.joblib and
  bbb_model_metadata.json. No CSV with test-set predictions,
  residuals, or molecule-level metrics is present. This prevents
  independent verification of the reported test R²=0.354.

GAP 2: Applicability domain not assessed
  The BBB model was trained exclusively on B3DB molecules, which are
  predominantly small CNS drugs and probe compounds. BACE1 inhibitors
  are structurally distinct (larger, more lipophilic, peptidomimetic
  scaffolds). No applicability domain analysis (e.g., Tanimoto
  distance to B3DB training set) has been performed for the BACE1
  molecules receiving BBB predictions.

GAP 3: Prediction uncertainty not propagated
  The bace1_continuous_bbb.csv uses a point estimate (predicted_logBB)
  without uncertainty bounds. Given RMSE=0.621 on the test set, the
  true logBB could plausibly range ±1.2 log units for any given
  prediction, which spans a large fraction of the BBB+/BBB- boundary
  (typically logBB > -1.0 for BBB-permeable).

GAP 4: Filtering threshold basis not documented
  The 'bbb_condition' and 'normalized_predicted_logBB' columns in
  bace1_continuous_bbb.csv imply a threshold was applied to select
  BBB-permeable candidates, but the rationale for the specific
  threshold value is not documented in the available files.

GAP 5: Column naming could mislead
  The column name 'predicted_logBB' is accurate, but downstream
  consumers of this data could mistake it for experimental logBB
  without reading the metadata. Any report should explicitly state
  that these are model predictions, not experimental measurements.

==============================================================
SECTION 5: VERDICT
==============================================================

The BBB filtering in the DrugGEN BACE1 pipeline is based on a
properly trained regression model (ExtraTrees, scaffold-split,
n_train=742, n_test=139) applied to B3DB experimental logBB data.
The model achieves test R²=0.354, which is modest but within the
range reported for logBB prediction in the literature.

Key points for any publication or report:
  1. ALWAYS state that BBB permeability scores are model predictions,
     not experimental measurements.
  2. Report test R²=0.354 as the benchmark for BBB model accuracy.
     Do NOT imply that BBB predictions are experimental or highly
     accurate.
  3. Acknowledge the applicability domain gap: the model was trained
     on B3DB molecules; BACE1 inhibitor scaffolds are largely outside
     the training domain.
  4. The conjunction of oracle pIC50 prediction (R²=0.6156) and BBB
     prediction (R²=0.354) means the joint uncertainty is substantial.
     Top candidates should be clearly labeled as 'computationally
     predicted' requiring experimental validation for both activity
     and BBB penetration.
